# 音频处理2：转换并合成

跳过FFmpeg音频处理，使用已有音频执行“杰理格式转换 → 合成dir_music”。

1. 调用 MCP 工具 `check_audio_environment`。转换工具、pRFiles、
   packres、new_packres.bat 必须全部存在；缺失时报告并停止。
2. 优先使用本次命令中通过 `@` 附加的 `processed` 文件夹或其父目录。
   没有附加路径时，将 `input_paths` 设为空列表，由 MCP 在项目中查找
   `processed`。
3. 调用 `start_audio_workflow`：

```json
{
  "input_paths": [],
  "workflow_step": 2
}
```

4. 保存 `job_id`，通过 `get_audio_workflow_status` 持续查询至终态，不要
   重复启动任务。简要报告转换数量和合成阶段。
5. 用户要求取消时调用 `cancel_audio_workflow`。
6. 成功时汇报 `converted`、`OUTPUT.LST` 和 `dir_music`；失败时汇报
   `error` 和最后相关日志。
