# 音频处理4：仅合成

跳过FFmpeg处理和格式转换，直接使用已有 `converted` 生成
`OUTPUT.LST` 和 `dir_music`。

1. 调用 MCP 工具 `check_audio_environment`。pRFiles、packres、
   new_packres.bat和test_dir必须存在；转换工具或FFmpeg缺失不影响本模式。
2. 优先使用本次命令中通过 `@` 附加的 `converted` 文件夹、`processed`
   文件夹或其父目录。没有附加路径时，将 `input_paths` 设为空列表。
3. 调用 `start_audio_workflow`：

```json
{
  "input_paths": [],
  "workflow_step": 4
}
```

4. 保存 `job_id`，通过 `get_audio_workflow_status` 持续查询至终态，不要
   重复启动任务。用户要求取消时调用 `cancel_audio_workflow`。
5. 成功时汇报 `OUTPUT.LST` 和 `dir_music` 的完整路径；失败时汇报
   `error` 和最后相关日志。
