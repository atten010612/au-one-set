# 音频处理0：完整流程

执行“音频处理 → 格式转换 → OUTPUT.LST与dir_music合成 → 强烧 → AD15n
授权”的完整流程。

1. 调用 MCP 工具 `check_audio_environment`。如果 `ready` 不是 `true`，
   列出 `missing` 并停止，不要改用 Shell 绕过。
2. 收集本次命令中通过 `@` 明确附加的文件和文件夹路径，保持路径不变。
   如果没有附加路径，将 `input_paths` 设为空列表，让 MCP 使用项目根目录。
3. 调用 `start_audio_workflow`：

```json
{
  "input_paths": [],
  "workflow_step": 0
}
```

4. 保存返回的 `job_id`，调用 `get_audio_workflow_status` 持续查询，直到
   `status` 为 `completed`、`failed` 或 `cancelled`。不要重复启动任务。
5. 查询期间简要报告阶段、百分比和 `current/total`。如果用户要求取消，
   调用 `cancel_audio_workflow`。
6. `dir_music` 生成后，流程会覆盖 `强烧工具\toy\dir_music`、删除旧的
   `jl_isd.fw`、在强烧工具目录执行 `download.bat`，再将新固件与
   `26华钜芯-AD15N-9016-AA515221.lkey` 载入 AD15n 授权工具，选择
   “无限制”并授权。
7. 完成后汇报 `artifacts` 中的 `processed`、`converted`、`OUTPUT.LST`、
   `dir_music`、`jl_isd.fw` 和 `authorized_firmware`；失败时汇报
   `error` 与最后相关日志。
