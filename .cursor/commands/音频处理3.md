# 音频处理3：仅格式转换

跳过FFmpeg音频处理，只使用杰理音频文件转换工具生成 `converted`。

1. 调用 MCP 工具 `check_audio_environment`。本模式要求转换工具存在；
   pRFiles、packres或new_packres.bat缺失不影响本模式。
2. 优先使用本次命令中通过 `@` 附加的 `processed` 文件夹或其父目录。
   没有附加路径时，将 `input_paths` 设为空列表。
3. 调用 `start_audio_workflow`：

```json
{
  "input_paths": [],
  "workflow_step": 3
}
```

4. 保存 `job_id`，通过 `get_audio_workflow_status` 持续查询至
   `completed`、`failed` 或 `cancelled`，不要重复启动任务。
5. 用户要求取消时调用 `cancel_audio_workflow`。
6. 成功时汇报 `converted` 路径和结果数量；失败时汇报 `error` 与最后
   相关日志。
