# 音频处理1：仅音频处理

只执行降噪、头尾裁剪、响度归一化和文件名去空格，不运行杰理转换或合成。

1. 调用 MCP 工具 `check_audio_environment`。本模式只要求 Python 和
   FFmpeg 可用；如果仅杰理工具缺失，可以继续。
2. 收集本次命令中通过 `@` 附加的文件和文件夹路径。没有附加路径时，
   将 `input_paths` 设为空列表，使用项目根目录。
3. 调用 `start_audio_workflow`，设置：

```json
{
  "input_paths": [],
  "workflow_step": 1
}
```

4. 使用返回的 `job_id` 调用 `get_audio_workflow_status`，持续查询至
   `completed`、`failed` 或 `cancelled`，不要重复启动。
5. 用户要求取消时调用 `cancel_audio_workflow`。
6. 成功时汇报 `processed` 路径；失败时汇报 `error` 和最后相关日志。
